# 视频级质检

静帧质检看不出时间维度上的毛病。`qc/video.py` 读成片（或帧目录），逐帧算指标。

```bash
python film.py video examples/x.json out/x-final.mp4
```

---

## 抓什么

| 检查 | 判据 | 抓的是 |
|---|---|---|
| **闪烁** | 镜内相邻帧亮度变化中位数 > 6，或单帧 > 16 | 颗粒/滤镜不稳定 |
| **卡顿** | 连续 ≥12 帧（0.4 秒）帧差低于镜内中位的 20% | 渲染丢帧、动画停住 |
| **意外硬切** | 镜内出现帧差 > max(12, 中位×4) | 本该只有镜头边界才有的跳变 |
| **字幕抖动** | 底部文字块逐帧水平位移 > 21px(1080p) | 排版回流（只在无图形镜头测） |
| **黑场** | 连续 ≥8 帧亮度 < 6 | 素材没加载 / 渲染失败 |
| **节奏塌方** | 镜头时长变异系数 < 0.22 | 全片一样长，没有呼吸 |
| **音频削波** | 峰值 > 0.995 | 混音过载 |
| **音频静音** | 超过 1 个「2 秒窗口」峰值 < 0.002 | 配乐没混上 / 断轨 |

---

## 校准过程中踩的坑

第一版报了 **34 条问题，全是误报**：

| 误报 | 原因 | 修法 |
|---|---|---|
| 132 帧"卡顿" | 抽帧降到 480p，0.04 的肯伯恩斯推拉被压平 | 抽帧提到 960p |
| 每个镜头都有"意外硬切" | 镜头边界那一帧的帧差被算进了新镜头 | 每镜跳过前 3 帧 |
| 字幕"抖动" 158px | 波束/光柱图形在底部有亮块，被当成文字 | 有 graphics 的镜头跳过抖动检测 |
| 卡顿阈值过严 | 绝对阈值 0.06 对慢速运动太苛刻 | 改成相对阈值 + 0.4 秒窗口 |

**校准后：0 误报。**

## 自检（单元测试）

质检器自己没被验证过，等于没有质检。`qc/selftest.py` 用合成数据构造已知毛病：

```bash
python film.py selftest
# 9/9 通过
```

| 用例 | 断言 |
|---|---|
| 正常运动画面 | 不报卡顿 |
| 冻结 20 帧 | **必须**报卡顿 |
| 亮度 ±25 抖动 | **必须**报闪烁 |
| 稳定亮度 | 不报闪烁 |
| 10 帧全黑 | **必须**报黑场 |
| 正常曝光 | 不报黑场 |
| 时长全相同 | **必须**报节奏塌方 |
| 长短交错 | 不报节奏 |
| 改字幕 vs 改标题 | 哈希分别变 / 不变 |

这是仓库里第一批真正的单元测试——之前所有验证都是"渲一遍看看"。

## 已知局限

| 局限 | 说明 |
|---|---|
| 只测"技术毛病" | 测不出"这段无聊" |
| 抖动检测有盲区 | 图形镜头被跳过（亮块会污染检测） |
| 音频检查粗 | 只查削波与静音，不查响度曲线 |
| 依赖抽帧 | 960p 抽帧 5400 帧约 90 秒 |
