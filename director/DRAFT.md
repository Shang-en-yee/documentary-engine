# 剧本 → 分镜草案

这是「前端自动化」的一半：**人只写叙事，结构交给引擎算。**

---

## 一份剧本长什么样

`scripts/galileo.script.json` —— 30 行撑起 3 分钟：

```json
{
  "title": "伽利略号的最后一天",
  "assets": { "launch": "assets/galileo/launch-8913765.jpg", "europa": "…" },
  "acts": [
    { "id": "a1", "title": "出发", "mood": "amber",
      "beats": [
        { "text": "1989 年 10 月 18 日\n亚特兰蒂斯号升空",
          "asset": "launch", "caption": "NASA · STS-34" },
        { "text": "没有一枚火箭\n能一次把它送到那里",
          "graphics": "timeline" }
      ] }
  ]
}
```

一个 `beat` 只有四个字段：

| 字段 | 说明 |
|---|---|
| `text` | 用 `\n` 分行；每行一条字幕 |
| `asset` | 素材 id；不写就是图形镜头 |
| `caption` | 左上角出处（可选） |
| `graphics` | 图形镜头用哪种：`timeline` / `dots` / `waves` |
| `accent` | 手动指定染金词；不写则自动染数字 |

---

## 生成

```bash
python film.py draft scripts/galileo.script.json --duration 180
# → examples/galileo-draft.json
```

引擎自动做的事：

| 规则 | 算法 |
|---|---|
| **镜头时长** | 字数 / 4.2 + 1.2（入）+ 0.8（出），夹在 3–12 秒 |
| **节奏塑形** | 单行短句 ×0.62（快切）；带出处长句 ×1.18（停留） |
| **总长归一** | 按 `--duration` 等比缩放，形状不变 |
| **推拉方向** | 逐镜交替，避免连续同向 |
| **素材选型** | 有 `asset` → archive 镜头；无 → 图形镜头 |
| **末镜** | 最后一幕最后一个 beat 自动用落版（光柱） |
| **素材复用** | 同一素材第二次出现自动换裁切，避免"一张图放三遍" |
| **暗素材补偿** | 读图算平均亮度，< 40 自动提亮（最高 2.6×） |
| **染金词** | 数字自动（年份、数量），可用 `accent` 覆盖 |
| **配色** | 幕 mood 五选一：amber / steel / jade / deep / neutral |

## 实测：伽利略号

| | 手写版 | 草案版 |
|---|---|---|
| 输入 | 23 个镜头逐条手写 | **30 行剧本** |
| 镜头数 | 23 | 21 |
| 时长 | 180s | 180s（归一化） |
| lint | 0 | 0 |
| style | 0 | 0 |
| preview | 0 | 0 |
| 人工后续 | — | 调配色 / 换结尾图形 / 微调节奏 |

**草案一次通过三道质检**，剩下的工作是审美而不是结构。

---

## 还缺什么

| 缺 | 影响 |
|---|---|
| 剧本本身还要人写 | 选题、事实核查、金句仍然靠人 |
| 素材提示要人指定 | 不做语义匹配（"这句该配哪张图"） |
| 节奏只有两条规则 | 没有真正的高潮曲线 |
| 配色只有五种 | 没有幕内渐变 |

**边界很清楚**：引擎能保证「写了什么就出现什么、多久、怎么动」，不能保证「写得对不对」。
